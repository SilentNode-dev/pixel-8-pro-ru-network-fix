# Pixel Russian Networks & 5G (n78/n79) / VoLTE / VoWiFi Fix

> **Низкоуровневый системный модуль (KernelSU / Magisk / APatch) для аппаратной адаптации модемов Samsung Shannon (Google Tensor G1/G2/G3/G4) под сети операторов РФ и MVNO: МегаФон, МТС, Билайн, Т2, Yota, СберМобайл, Т-Банк, ВТБ Мобайл, Газпромбанк Мобайл, Мотив, Таттелеком (Летай), Ростелеком, Next Mobile, Wifire.**
> 
> Разблокирует аппаратный диапазон 5G n79, агрегацию частот LTE-Advanced (до 5CA), VoLTE, VoWiFi, VoNR, Google Messages RCS, авто-настройку APN, интерактивный WebUI и CLI-утилиту `netfix` без установки сторонних фоновых приложений.
> 
> **Совместимость:** Android 14, 15, 16, 17+ (проверено на Pixel 6, 6 Pro, 6a, 7, 7 Pro, 7a, 8, 8 Pro, 8a, 9, 9 Pro, 9 Pro XL, 9 Pro Fold).

## ⚡ Технические возможности v1.2

### 1. Модемный уровень (Baseband & Radio)
* **Сертифицированные профили Samsung Shannon SER**: калибровки и параметры радиомодуля извлечены и интегрированы из официальной российской прошивки Samsung Galaxy A55 5G (`A556EXXUIEZJ1`, Exynos 1480 / Shannon baseband family).
* **Активация 5G NR (NSA + SA)**: включение диапазонов **n78 (3.4–3.8 ГГц)** и **n79 (4.4–5.0 ГГц)**, а также n1, n3, n8, n28, n41, DSS. Диапазоны 5G работают на полной мощности без искусственных ограничений пропускной способности.
* **Снятие RRC-фильтрации n79**: устранение аппаратного блокирования диапазона n79 в модеме Shannon через подмену стека `uecap`.
* **Агрегация частот LTE-Advanced (4G+)**: разблокировка полной матрицы агрегаций (3CA / 4CA / 5CA) с поддержкой MIMO 4x4 и модуляции 256-QAM (комбинации B1+B3, B3+B7, B1+B3+B7, B7+B20, B3+B38, B38+B38 и др.).
* **Голос нового поколения (VoNR / Vo5G)**: аппаратная и программная поддержка голосовых вызовов высокой чёткости внутри сетей 5G Standalone.
* **Отключение устаревших стандартов**: заблокирован паразитный фоновый поиск CDMA/EVDO сетей, отсутствующих в РФ, что экономит заряд батареи в зонах неуверенного приёма.

### 2. Подсистема IMS (IP Multimedia Subsystem)
* **VoLTE (Voice over LTE)**: пакетная передача голоса на обеих SIM-картах (Dual SIM Dual Standby — физ. SIM + eSIM).
* **VoWiFi (Wi-Fi Calling)**: прямое подключение к шлюзам ePDG российских операторов, разблокировка ручного выбора приоритета сети (Cellular preferred / Wi-Fi preferred).
* **Backup Calling (Cross-SIM IMS)**: возможность совершать звонки по VoWiFi через мобильный интернет второй SIM-карты при отсутствии покрытия на первой.
* **ViLTE / VT (Video over LTE)**: поддержка нативных операторских видеозвонков.
* **Услуги связи через Ut / XCAP**: управление переадресацией, запретом и ожиданием вызовов через мобильный интернет без падения в 2G/3G.
* **Google Messages RCS (Jibe Cloud Bypass)**: обход операторских ограничений RCS — автоматическое прямое подключение к облаку Google Jibe через мобильный интернет.

### 3. Автоматизация и управление (Новое в v1.2)
* **KernelSU / KernelSU Next WebUI**: встроенный графический интерфейс управления прямо в приложении KernelSU с Material You оформлением, мониторингом сети и тумблерами функций для каждого слота SIM.
* **Консольная утилита `netfix`**: полноценный CLI в `/system/bin/netfix`:
  * `netfix status` — сводка состояния базовой полосы, inode монтирования, IMS и активной сети.
  * `netfix reload` — мгновенное переприменение оверрайдов к телефонии на лету.
  * `netfix apn` — автоматическое создание точек доступа (APN) для российских MVNO.
  * `netfix log` — вывод актуальных логов модема и IMS.
* **SIM Hot-Swap & Airplane Mode Watcher**: бессерверный слушатель системных событий с 0% нагрузки на CPU. При переключении авиарежима или смене SIM-карты модуль автоматически за секунды восстанавливает все инъекции без необходимости перезагружать устройство.
* **Автоматическая настройка APN**: сертифицированные параметры точек доступа для Yota, СберМобайл, Т-Банк, Газпромбанк Мобайл, ВТБ Мобайл, Мотив, Летай и T2.

## 🔬 Архитектура и принцип работы

Модуль воздействует на стек связи комплексно — от физических образов модема до IPC-сервисов Android Framework:

```
[ Этап 1: post-fs-data.sh ]
       │
       ├── mount --bind uecap/WILDCARD.binarypb ➔ /mnt/vendor/modem_img/images/*/uecap/WILDCARD.binarypb
       │   └── Снимает RRC-блокировки n78/n79, подменяет capability-профиль модема.
       │
       └── mount --bind confpack/cfg.db ➔ /mnt/vendor/modem_img/images/*/confpack/cfg.db
           └── Подменяет базу модема Shannon: содержит сертифицированные PLMN/SPN маппинги SER.

[ Этап 2: service.sh (boot_completed) ]
       │
       ├── setprop persist.dbg.* & persist.radio.* ➔ открывает флаги VoLTE/VoWiFi/VoNR.
       ├── content update telephony/siminfo ➔ принудительно включает IMS в таблице SIM.
       ├── netfix apn ➔ инжектирует сертифицированные APN для российских MVNO.
       ├── CLASSPATH=Applier.dex app_process ➔ вызывает ICarrierConfigLoader через Binder IPC.
       │
       └── Background Watcher (resetprop -w gsm.sim.state) ➔ авто-инъекция при смене SIM / Авиарежиме.
```

## 📦 Установка

1. Скачайте **`Pixel_8_Pro_RU_5G_VoLTE_Fix.zip`** из раздела [Releases](https://github.com/SilentNode-dev/pixel-8-pro-ru-network-fix/releases).
2. Откройте **KernelSU**, **KernelSU Next**, **Magisk** или **APatch**.
3. Перейдите во вкладку *«Модули»* ➔ *«Установить из хранилища»* ➔ выберите архив.
4. Перезагрузите устройство.
5. Для проверки откройте терминал (Termux / ADB) и введите `su -c netfix status` либо откройте страницу модуля в KernelSU.

## 🛠 Команды утилиты `netfix`

```bash
# Проверить полный статус подключения, IMS и модема:
netfix status

# Переприменить все настройки связи без перезагрузки:
netfix reload

# Добавить недостающие APN операторов РФ:
netfix apn

# Просмотреть радио-логи IMS в реальном времени:
netfix log
```
